# Histórias de Usuário (User Stories)

## Épico 1: Descoberta e Filtragem
- **US01:** Como um usuário com mobilidade reduzida, eu quero selecionar a necessidade de "Mobilidade" para que o sistema me mostre apenas roteiros adaptados para cadeirantes.
- **US02:** Como um turista idoso, eu quero selecionar a preferência "Mais pausas" para encontrar roteiros que possuam bancos e áreas de descanso.
- **US03:** Como um usuário visitante, eu quero poder pular a etapa de seleção de preferências para ir direto para a exploração de roteiros.

## Épico 2: Visualização da Informação
- **US04:** Como um usuário visitante, eu quero ver uma imagem e um breve resumo do local no card de roteiro para entender rapidamente do que se trata.
- **US05:** Como uma pessoa cega ou com baixa visão acompanhada, eu quero saber com clareza a fonte da informação de acessibilidade e a data em que ela foi verificada, para ter segurança antes de me deslocar.
- **US06:** Como um usuário visitante, eu quero ser avisado por meio de alertas visuais caso haja algum impeditivo grave no percurso (ex.: calçamento irregular de pedras).
